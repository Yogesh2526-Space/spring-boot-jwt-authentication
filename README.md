# Spring Boot JWT Authentication

A Spring Boot REST API project with MySQL, Spring Data JPA, Spring Security, and JWT-based authentication.

## Features

- User registration
- User login
- BCrypt password encryption
- JWT token generation
- JWT token validation
- JWT authentication filter
- Protected REST APIs
- Spring Data JPA
- MySQL database
- Input validation
- Swagger/OpenAPI

## Technologies Used

- Java
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- MySQL
- Maven
- Postman

## Authentication Flow

Register → Login → Receive JWT → Send Bearer Token → JWT Filter → Validate Token → Access Protected API
